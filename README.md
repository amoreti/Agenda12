📘 Meus Sites Favoritos
Este projeto é uma página web simples desenvolvida como atividade do curso técnico de Desenvolvimento de Sistemas.
O objetivo é criar uma página HTML contendo uma lista dos meus sites favoritos, cada um com nome, imagem e link clicável.

🎯 Objetivo da atividade
- Criar uma página HTML com:
    - Título da aba: Meus sites favoritos
    - Título principal no corpo: Meus sites favoritos: Amanda Moreti Santos
    - 5 sites favoritos, cada um contendo:
        - Nome do site
        - Imagem representando o site
        - Link clicável abrindo em nova aba
- Organizar o conteúdo usando:
    <!--<section>
    <ul> e </ul>
    <h1> e <h2>
    <a>
    <img>-->
- Subir o pojeto completo no GitHub

🧩 Tecnologias utilizadas
- HTML5
- Estrutura semântica com imagens locais
